# SPK MM Client 1.0.0

Первый релиз с готовыми пакетами нативного клиента Mattermost.

Несколько серверов, вход по паролю и через GitLab, сообщения, треды, поиск и черновики. Вложения и просмотр изображений, PDF, текста, Markdown, аудио и видео. Интерфейс приложения на русском и английском. Видимая кнопка «О приложении», фактическая версия сборки, Apache License 2.0 и ссылки на проект и автора.

Быстрые переключения реакций сохраняют последний выбор при запоздавших событиях сервера.

Пакеты Linux, Windows и macOS для amd64 и arm64, контрольные суммы SHA-256 и полные тексты лицензий зависимостей. macOS: ad-hoc подпись без нотарификации. Windows: без Authenticode, нужен WebView2. Linux: glibc 2.39+, GTK3, WebKitGTK 4.1. Browser-архивы для разработчиков отдельные; автообновление и AppImage в этот выпуск не входят.

Сайт: https://sipaha.github.io/spk-mm-client/
Поддержать автора: https://sipaha.github.io/about/?lang=ru#support
