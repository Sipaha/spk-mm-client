# SPK MM Client 1.0.3

- Абзацы заметнее разделены в сообщениях, тредах и предпросмотре черновика. Обычные переносы строк и короткие сообщения остаются компактными.
- В Linux системные уведомления убираются после прочтения сообщений, в том числе из другого клиента. Это очищает зависшие индикаторы уведомлений на панели задач Cinnamon.
- Прочитанные уведомления не появляются повторно после завершения задержки группировки сообщений. Обновления уведомлений повторяются после временной недоступности системного сервиса.
- Сообщение, которое вы читаете, остаётся на месте при последовательной догрузке нескольких страниц разрыва истории, в том числе при высокой нагрузке на интерфейс.
- Linux-ярлык сборки для разработки отделён от установленного релиза: у него собственные имя и иконка.
- В README добавлены иконка приложения, значки релиза и ссылки навигации.

Расширения Cinnamon и изменение настроек системы не требуются. Трей показывает состояние непрочитанного и упоминаний в клиенте, а панель Cinnamon считает сохранённые системные уведомления: при наличии непрочитанных уведомлений числа могут различаться.

Сохранены пакеты Linux, Windows и macOS для amd64/arm64, SHA-256 и проверка настоящих production-окон. Подписи пакетов и системные требования прежние.
