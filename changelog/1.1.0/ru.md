# SPK MM Client 1.1.0

- Сборка переведена на Go 1.26.10 с обновлением безопасности проверки доверия сертификатов crypto/x509 (GO-2026-6809).
- Добавлена диктовка сообщений на русском языке в композерах канала и треда через локальный SPK LAIHub с GigaAM.
- Распознанный текст добавляется в редактируемый черновик и сохраняется обычным способом. Сообщение отправляется отдельно; аудио не прикрепляется к нему и не сохраняется клиентом.
- Запись длится до 60 секунд; её можно завершить раньше или отменить. Уход из разговора, скрытие приложения или запуск диктовки в другом месте освобождает микрофон и исключает позднюю вставку текста.
- Ошибки доступа к микрофону и распознавания показываются без потери черновика. В macOS-пакеты добавлено объяснение запроса доступа к микрофону.

Для диктовки нужен запущенный SPK LAIHub с речевым API на loopback-порту 8095 и доступной моделью GigaAM. Клиент не устанавливает модели и не запускает LAIHub. Настройка и границы проверки описаны в отдельной документации по диктовке.

Сохраняются нативные пакеты Linux, Windows и macOS для amd64/arm64 и контрольные суммы SHA-256. Требования к окружению и подписи не менялись.
