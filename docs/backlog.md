# Бэклог (низкий приоритет)

Приоритет проекта — рабочий клиент, которым можно заменить официальный
(решение пользователя 2026-09-24). Мелочи ниже делаются, но после ядра.

- **Настройка языка UI** «Как в системе / Русский / English». Сейчас язык
  следует языку сообщений системы (gettext: `LANGUAGE`, `LC_ALL` >
  `LC_MESSAGES` > `LANG`) — см. `docs/spikes/2026-09-24-stage1-spikes.md` S5.
- Мелочи из ревью этапа 1: временный home e2e не удаляется; поздно
  стартовавший notifier может оставить D-Bus-соединение; тело успешного
  REST-ответа не дочитывается; `ErrServerExists` определяется по тексту
  ошибки; просроченные SSO-входы чистятся только в `Complete`; холодный
  старт по `mmauth://` (приложение не запущено) всегда `no_pending_login`,
  а токен виден в `/proc/<pid>/cmdline`.
