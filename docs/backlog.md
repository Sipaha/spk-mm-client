# Бэклог (низкий приоритет)

Приоритет проекта — рабочий клиент, которым можно заменить официальный
(решение пользователя 2026-09-24). Мелочи ниже делаются, но после ядра.

- **Настройка языка UI** «Как в системе / Русский / English». Сейчас язык
  следует языку сообщений системы (gettext: `LANGUAGE`, `LC_ALL` >
  `LC_MESSAGES` > `LANG`) — см. `docs/spikes/2026-09-24-stage1-spikes.md` S5.
- Мелочи из ревью этапа 1 (`ErrServerExists` уже закрыт — теперь sentinel-ошибка
  с `errors.Is`, не сравнение текста): временный home e2e не удаляется; поздно
  стартовавший notifier может оставить D-Bus-соединение; тело успешного
  REST-ответа без `out` не дочитывается (новое TCP-соединение на каждый такой
  запрос вместо переиспользования keep-alive); просроченные SSO-входы чистятся
  только в `Complete`; холодный старт по `mmauth://` (приложение не запущено)
  всегда `no_pending_login`, а токен виден в `/proc/<pid>/cmdline`.
- Живая проверка этапа 2 на mm.citeck.ru (задача 16, шаг 5) — не выполнена в
  этой сессии по решению контроллера, перенесена на отдельный проход вместе
  с пользователем; статус — «в очереди», см. статус в спецификации.
