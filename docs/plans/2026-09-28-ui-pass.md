# UI-проход: панель действий при наведении, реакции крупнее, монохромные иконки

Источник — живая проверка пользователя 2026-09-28:
- при наведении на сообщение нужна панель действий как в официальном клиенте: 3 быстрые реакции из недавних эмодзи пользователя, «добавить реакцию», «сохранить», «ответить в треде» и меню «…»;
- чипы реакций и кнопки «микроскопические», их нужно сделать крупнее;
- эмодзи-глифы в роли иконок интерфейса (⬇️ ↗️ 📎 ⤢ 📄 …) не подходят к тёмной теме, их нужно заменить монохромными SVG;
- иконка загрузок в шапке — в стиле Material: лоток со стрелкой вниз.

«Ответить в треде» (↩N) приходит вместе с планом тредов (`docs/plans/2026-09-28-threads.md`). Здесь в панели оставлено место под эту кнопку, но самой кнопки нет.

## Дизайн

Решения контроллера (в реестре SDD как Ruling):
- **Иконки.** Один модуль `frontend/src/components/icons.tsx` с инлайн-SVG-компонентами без зависимостей:
  - `viewBox="0 0 24 24"`, `fill="currentColor"`, по умолчанию 18 px, у каждого `size?: number` и `className?: string`, `aria-hidden="true"`, `focusable="false"`;
  - пути — Material Symbols / Material Icons (Apache-2.0, указать в шапке файла);
  - библиотеку иконок не подключаем: бандл и память дороже 25 путей.
- **Что заменяется.** Любой глиф, который служит иконкой в кнопке, ссылке, чипе, строке списка или бейдже. Комментарии, тексты i18n и подсказки клавиш («←/→») не трогаются. Настоящие эмодзи сообщений и реакций остаются эмодзи.
- **Быстрые реакции — как в веб-клиенте** (`getOneClickReactionEmojis`, Mattermost 10.11 `webapp/channels/src/selectors/emojis.ts:100`):
  - берутся первые 3 из `EmojiDTO.recent` (у нас он уже «самые частые первыми» = `slice(-3).reverse()` веб-клиента);
  - неизвестные имена отфильтровываются: не стандартные и не из `custom`;
  - при пустом списке быстрых реакций нет, как в веб-клиенте.
  - Нажатие ставит реакцию. Если наша такая реакция уже есть, нажатие снимает её (как клик по чипу).
- **Кэш недавних эмодзи на фронте.**
  - Модуль `frontend/src/emoji/recent.ts` хранит по серверу последний `EmojiDTO`, запрошенный через `api.emojiInfo`.
  - Запрос уходит при первом показе панели на сервере; после каждой нашей реакции (`actions.react` с `add`) кэш помечается устаревшим и перечитывается при следующем показе.
  - Ограничен числом серверов; при удалении сервера запись удаляется.
  - Отклонено: запрос `emojiInfo` при каждом наведении — лишние вызовы на каждое движение мыши.
- **Панель рендерится только для «горячего» поста.**
  - Сейчас тулбар есть в DOM у каждого поста и скрыт CSS. С эмодзи-картинками быстрых реакций каждый скрытый тулбар грузил бы картинки.
  - Поэтому `PostItem` держит `hot`: `true` по `pointerenter` и `focusin`; `false` по `pointerleave` и `focusout`, если фокус ушёл из статьи и не открыто ни меню «…», ни пикер.
  - Состояние живёт внутри `memo`-компонента и не трогает виртуализатор.
- **Состав панели** слева направо: 3 быстрые реакции | добавить реакцию | сохранить | (место под «ответить», план тредов) | «…».
  - Меню «…» — выпадающий список (портал в `document.body`, закрывается по Esc и клику снаружи, фокус возвращается на «…»). Пункты: «Отметить непрочитанным», «Копировать ссылку», «Изменить» и «Удалить» (последние два — только свои не системные посты).
  - Пункты меню — кнопки с иконкой и текстом; ↑/↓ ходят по пунктам, Enter выбирает.
- **Размеры.**
  - Кнопки панели — 32×32, иконки 20 px, эмодзи быстрых реакций 20 px.
  - Чипы реакций — высота 28 px, эмодзи 18 px, счётчик `text-sm`; кнопка «добавить реакцию» у чипов — того же размера, с иконкой `IconAddReaction` вместо «☺+».
  - Панель висит `-top-4`, чтобы не перекрывать текст однострочного поста сильнее, чем сейчас.
- **«Сохранить»** = флаг поста, как в веб-клиенте: предпочтение `flagged_post`, имя — id поста, значение `"true"`. Снятие — удаление предпочтения.
  - `PostView.saved` вычисляется из предпочтений в state.
  - События `preferences_changed` и `preferences_deleted` уже применяются к предпочтениям (`internal/state/events.go:129`); лента должна перерисовываться, когда меняется `flagged_post`.
  - Отдельного экрана «Сохранённые» нет: сохранённое видно в официальных клиентах. Экран — в бэклог.

## Global Constraints

Те же, что у плана вложений (`.superpowers/sdd/2026-09-28-ui-pass/constraints.md` — копия):
- Go 1.26, Wails v3.0.0-beta.25; `go test -race`, `go vet` и `golangci-lint` для обоих наборов тегов (`""` и `"wails gtk3"`); `go build ./...` без тегов проходит.
- Фронтенд: `pnpm test && pnpm lint && pnpm build`.
- i18n ru/en с паритетом ключей.
- Доступность: у каждой кнопки-иконки `aria-label` и `title`; SVG — `aria-hidden`; меню доступно с клавиатуры.
- UI ходит только в `api.API` и `/media/`.
- Кэши ограничены, память не растёт; ничего блокирующего на старте.
- Коммиты — репозиторная идентичность, без amend и Co-Authored-By, только явные пути.
- Playwright-контексты закрываются в том же вызове.
- Живой клиент пользователя и `/opt/Mattermost` не трогать; pkill/killall запрещены.
- `build/bin/spk-mm-client-desktop` не пересобирать; проверочные сборки — под `.agents/tmp`.
- Скриншоты «до/после» — browser mode на своём порту, в `.agents/tmp/ui-pass/`.

## Review Focus

1. Длинная лента: наведение мышью по многим постам подряд не должно ни создавать запросов `emojiInfo` на каждый пост, ни грузить картинки эмодзи у постов без наведения. Тест: `PostItem` без наведения не рендерит тулбар; `recent.ts` делает один запрос на сервер, пока кэш не помечен устаревшим.
2. Кастомный эмодзи в недавних, удалённый на сервере (нет в `custom`). Его не должно быть в быстрых реакциях, и дыры на его месте тоже. Тест в `recent.ts`.
3. Открытое меню «…» или пикер, а указатель ушёл с поста. Панель не должна исчезать, пока меню открыто. Тест в `PostItem.test.tsx`.
4. Ожидающий, неотправленный или системный пост. У него нет ни быстрых реакций, ни «сохранить», как и сейчас. Тест.
5. Сохранение офлайн или при `needs_reauth` (`session_expired`). Нужна понятная ошибка без «залипшего» состояния кнопки. Тест в Go (`s.writer()` отказывает) и в UI (флаг берётся из `PostView.saved`, а не из оптимистичного локального state).

### Task 1: Монохромные SVG-иконки вместо эмодзи-глифов, иконка загрузок-лоток

**Files:** новый `frontend/src/components/icons.tsx` (+ `icons.test.tsx`); замены в `Composer.tsx`, `TextSnippet.tsx`, `FileCard.tsx`, `AttachmentsTray.tsx`, `MediaPlayer.tsx`, `ChannelPane.tsx`, `Downloads.tsx`, `Markdown.tsx`, `Sidebar.tsx`, `Viewer.tsx`, `MarkdownSnippet.tsx`, `Reactions.tsx`, `PostItem.tsx` (только глифы тулбара; структуру панели меняет Task 2) и их тесты.

- Компоненты (имена фиксированы — ими пользуются Task 2 и 3):
  - `IconDownload` — Material Symbols «download»: стрелка вниз в лоток; кнопка загрузок в шапке и «Скачать» у файлов.
  - `IconOpenExternal`, `IconAttach` (скрепка), `IconExpand` (open_in_full), `IconFile`, `IconImage`, `IconVideo`, `IconAudio`, `IconNote` (markdown/текст), `IconFolder`, `IconClose`, `IconAddReaction` (add_reaction), `IconEdit`, `IconMarkUnread` (mark_chat_unread), `IconLink`, `IconDelete`, `IconMore` (more_horiz), `IconBookmark` / `IconBookmarkFilled` (сохранить), `IconChevronRight` / `IconChevronDown`, `IconPlay`, `IconReply` (reply; понадобится тредам).
- Общий `Icon`-враппер: `({ size = 18, className, children })` → `<svg viewBox="0 0 24 24" width={size} height={size} fill="currentColor" aria-hidden="true" focusable="false" className={className}>`.
- Замены: каждый глиф-иконка из списка `grep -nP '[\x{2190}-\x{2BFF}\x{1F300}-\x{1FAFF}]'` по `frontend/src/components/*.tsx` вне комментариев, строк i18n и подсказок клавиш.
  - `Downloads.tsx`: `KIND_GLYPH` → `KIND_ICON` (компонент по виду файла).
  - `Markdown.tsx`: 🖼 у картинки-ссылки → `IconImage size={14}` inline.
  - `Sidebar.tsx`: ⋯ → `IconMore`, ▸/▾ → шевроны.
  - `MediaPlayer.tsx`: 🎵/▶/⤢ → иконки.
- Кнопки с иконками выравниваются flex-центром; размер кликабельной области не меньше прежнего.
- Бейдж числа активных загрузок остаётся на кнопке `IconDownload`.
- Тесты:
  - `icons.test.tsx`: каждая иконка рендерит `svg` с `aria-hidden` и `fill="currentColor"`, размер по пропу.
  - Существующие тесты, искавшие кнопки по тексту-глифу, переводятся на `getByRole(..., { name })`.
  - Новый тест-страж `noEmojiIcons.test.ts`: читает исходники `components/*.tsx` (через `import.meta.glob('./*.tsx', { query: '?raw', eager: true })`) и падает, если вне комментариев в JSX-тексте или строковых литералах встречается символ из диапазонов U+1F300–U+1FAFF, U+2190–U+21FF, U+2300–U+23FF, U+25A0–U+25FF, U+2700–U+27BF (исключения — явный allowlist с причинами, например `emoji/`).
- Скриншоты browser mode, до и после: шапка канала (кнопка загрузок с бейджем), панель загрузок, карточка файла, превью текста/markdown, композер со скрепкой, сайдбар с шевронами.
- Коммит: `ui: monochrome SVG icons instead of emoji glyphs; tray-style downloads icon`.

### Task 2: Панель действий при наведении, быстрые реакции, крупные чипы

**Files:** новый `frontend/src/emoji/recent.ts` (+ тест), новый `frontend/src/components/PostMenu.tsx` (+ тест), `PostItem.tsx`, `Reactions.tsx`, `Feed.tsx`/`ChannelPane.tsx` (прокидывание `emojiInfo`, если нужно), `i18n.ts`, тесты `PostItem.test.tsx`, `Reactions.test.tsx`.

**Interfaces:**
- Consumes: иконки из Task 1 (`IconAddReaction`, `IconMore`, `IconEdit`, `IconMarkUnread`, `IconLink`, `IconDelete`); `PostActions.emojiInfo(): Promise<EmojiDTO>`.
- Produces:
  - `recent.ts`: `useQuickReactions(serverId: number, load: () => Promise<EmojiDTO>): string[]` — до 3 имён; `invalidateRecent(serverId: number): void`; `forgetRecent(serverId: number): void`.
  - `PostItem`: `data-testid="post-toolbar"` у панели; слот `{replyButton}` — пока `null`, треды подставят `IconReply`.

- `recent.ts`: `Map<number, { dto?: EmojiDTO; stale: boolean; inflight?: Promise<void> }>` + подписчики (`useSyncExternalStore`).
  - Быстрые = `dto.recent.filter(n => emojiChar(n, null) || dto.custom.includes(n) || (idx && emojiChar(n, idx))).slice(0, 3)`.
  - Ошибка загрузки — пустой список и `stale = true`; повторный запрос — при следующем показе, не чаще одного в 30 с.
  - `forgetRecent` вызывается там же, где фронт забывает удалённый сервер (`store.ts`).
- `PostItem`:
  - `hot` (см. Дизайн); тулбар рендерится только при `hot || menuOpen || picker`.
  - Кнопки 32×32 (`h-8 w-8`), быстрые реакции — `EmojiGlyph size={20}`, `aria-label` = `t('reaction.quick', { emoji: ':name:' })`.
  - Клик по быстрой реакции: если у поста наша такая реакция — снять, иначе поставить (`actions.react`), затем `invalidateRecent(serverId)`.
  - `IconAddReaction` открывает пикер (как сейчас).
  - Место под «сохранить» (Task 3) и «ответить» (треды).
  - `IconMore` открывает `PostMenu`.
- `PostMenu`: портал; позиция — под кнопкой или над ней при нехватке места (переиспользовать правило `placePanel` из `Downloads.tsx`, вынести в общий `placeBelow(anchor, vw, vh, w, h)`, если нужно).
  - `role="menu"`, пункты `role="menuitem"` с иконкой и текстом; ↑/↓/Home/End, Enter/Space, Esc закрывает, клик снаружи закрывает, фокус возвращается на «…».
  - Пункты: `post.markUnread`, `post.copyLink`, `post.edit` и `post.delete` (свои, не системные).
- `Reactions.tsx`: чип `h-7 px-2 gap-1.5 text-sm`, `EmojiGlyph size={18}`; кнопка добавления — `h-7 w-9` с `IconAddReaction size={18}`, без текста «☺+».
- i18n: `reaction.quick` («Реакция {emoji}» / «React with {emoji}»), `post.more` («Ещё» / «More actions»).
- Тесты (vitest):
  - нет тулбара без наведения; тулбар по `pointerenter` и по фокусу; остаётся при открытом меню после `pointerleave`;
  - быстрые реакции из `emojiInfo` (первые 3, неизвестные отфильтрованы, пусто — ни одной);
  - клик ставит и снимает реакцию; `emojiInfo` вызывается один раз на сервер при наведении на несколько постов;
  - меню: состав для своего и чужого поста, клавиатура, Esc возвращает фокус;
  - ожидающий или системный пост без быстрых реакций;
  - `Reactions` — размеры (классы) и кнопка с `aria-label`.
- Скриншоты до и после: пост с наведением (панель с 3 быстрыми реакциями), открытое меню «…», пост с несколькими чипами реакций.
- Коммит: `ui: hover action bar with quick reactions and a more-menu; bigger reaction chips`.

### Task 3: «Сохранить» (flagged_post) — Go и кнопка в панели

**Files:** `internal/mm/rest/write.go` (+ тест), `internal/mmfake/chat.go` (+ тест), `internal/state/view.go` и место сборки `PostView` (+ тесты), `internal/mmsync` (действие сохранения; + тест), `internal/api/chat.go` или `internal/api/reactions.go` (привязка; + тест), `frontend/src/api/client.ts`, `api/types.ts`, `chat.ts`, `PostItem.tsx`, `i18n.ts` (+ тесты).

**Interfaces:**
- Produces: REST `func (c *Client) DeletePreferences(ctx context.Context, prefs []model.Preference) error` → `POST /api/v4/users/me/preferences/delete`; привязка `SetPostSaved(ctx, id int64, postID string, saved bool) error` (через `s.writer()` — `session_expired` при `needs_reauth`); `PostView.Saved bool json:"saved,omitempty"`; фронт `api.setPostSaved(id, postId, saved)`, `PostActions.save(post: PostView, saved: boolean): void`.

- Фейк: `POST /api/v4/users/me/preferences/delete` удаляет предпочтения и публикует `preferences_deleted` (формат как у `preferences_changed`).
- State:
  - `Saved` = есть предпочтение `flagged_post`/`postID` со значением `"true"`;
  - изменение или удаление `flagged_post` (REST-ответ или WS) помечает канал поста изменённым, чтобы лента перерисовалась, — как делают реакции.
- Воркер:
  - сохранение — `SavePreferences`, снятие — `DeletePreferences`;
  - успешный ответ сразу обновляет state, не дожидаясь WS; ошибка возвращается вызывающему;
  - POST не повторяется автоматически.
- UI:
  - кнопка в панели — `IconBookmark` (не сохранено) / `IconBookmarkFilled` + `text-accent` (сохранено);
  - `aria-pressed`, `aria-label` — `post.save`/`post.unsave` («Сохранить» / «Убрать из сохранённых»; ключ `post.save` уже занят кнопкой правки — новый ключ `post.saveForLater`);
  - состояние берётся только из `post.saved`, ошибка показывается как у прочих действий (`lastError`/тост, как у `markUnread`).
- Тесты:
  - Go: REST delete; фейк delete + событие; state `Saved` из prefs и из событий `changed`/`deleted`; воркер save/unsave; привязка при `needs_reauth` → `session_expired`.
  - UI: кнопка по `saved`, вызов `setPostSaved`, ошибка.
  - e2e (`tests/e2e/chat.spec.ts`): навести → «Сохранить» → кнопка нажата; перезагрузка страницы → всё ещё сохранено; снять.
- Скриншот: панель с сохранённым постом.
- Документы:
  - спека — раздел ленты: панель действий, быстрые реакции, сохранение;
  - `AGENTS.md` — правила «тулбар только у горячего поста — `PostItem.test`», «иконки — SVG из `icons.tsx`, тест-страж»;
  - `docs/backlog.md` — экран «Сохранённые», настройка «быстрые реакции вкл/выкл».
- Коммит: `posts: save for later (flagged_post) from the hover bar; docs`.
