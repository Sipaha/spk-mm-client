# Поиск по сообщениям и переход к сообщению в контексте

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (рекомендуется) или superpowers:executing-plans; без superpowers в рантайме — обычный порядок: задача → тесты → ревью. Шаги — чекбоксы.
>
> Редакция 2 плана: учтено ревью плана Codex (10 пунктов) и факты Task 1 (движки поиска bleve/SQL).

**Goal:** серверный поиск по сообщениям текущей команды с результатами в правой панели, подсветкой и подсказками `from:`/`in:`, и полноценный переход к любому (в т.ч. старому) сообщению канала или треда.

**Architecture:** у активного канала в Go к окну и истории `s.older` добавляется явный разрыв (`olderGap`) — переход заменяет историю сегментом вокруг поста, лента догружает разрыв страницами `after=` до окна; поколения (`histGen`, `gapGen`) отбрасывают запоздалые страницы. Для CRT-ответов старше 200 — «фокус треда»: скользящее окно ответов вокруг цели. Поиск — синхронный вызов по образцу `Autocomplete`; правая панель обобщается до `thread | search`.

**Tech Stack:** Go 1.26, Wails v3.0.0-beta.25, React 19 + Zustand + Tailwind 4, `@tanstack/react-virtual`, `react-markdown`/remark, Vitest, Playwright.

**Spec:** `docs/specs/2026-09-30-search-design.md` (согласовано с Codex; **обязателен к чтению** — инварианты, «Уточнения реализации», список регрессий). Правила — `AGENTS.md`; факты API — `docs/research/2026-09-24-mattermost-api-facts.md`; исходники MM 10.11 — `/home/spk/.spk/sawe/ss/Mattermost/.agents/tmp/mm-10.11`.

## Review Focus

1. **Живой поток во время перехода.** Пользователь перешёл к старому посту, в канал пришло > 60 новых сообщений, затем он догружает разрыв — ни одно не потеряно и не задвоено. — Task 2: `TestGapTrimDoesNotLeakIntoOlder`, Task 3: `TestJumpThenBurstThenFillGapLosesNothing`.
2. **Переход, отменённый новым действием.** A→B→A, jump1→jump2, запоздалый `LoadOlder` — страница прежней операции не попадает в новый сегмент; фронт не запускает `openThread`/прокрутку устаревшего перехода. — Task 3: `TestStalePagesAreDroppedAcrossJumps`; Task 6: `jump superseded by another jump does nothing`.
3. **Офлайн и overflow с открытым сегментом.** Правка/удаление поста сегмента во время офлайна; после реконнекта с since-overflow сегмент сохраняется, помечается stale и перепроверяется. — Task 2: `TestSetWindowOverflowKeepsSegmentAsStale`; Task 3: `TestStaleSegmentIsRevalidated`.
4. **Прокрутка «прыгает».** Догрузка разрыва сверху и снизу, WS во время загрузки, открытие правой панели/resize — видимый пост остаётся на месте; переход центрирует цель. — Task 6: Feed-тесты и e2e `gap fill keeps position`.
5. **Кириллица и спецсимволы в подсветке.** `привет`, `прив*`, `"точная фраза"`, `from:bob`, `-исключение`, термин внутри ссылки/кода — подсвечивается только текст, фильтры и отрицания — нет. — Task 7: `highlight.test.ts`.
